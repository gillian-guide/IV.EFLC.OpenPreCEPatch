# Credits

OpenPreCEPatch is a community successor to ZolikaPatch. It exists because
Zolika1351 published the mod, then left it closed and unmaintained; the
reconstruction and the readable rewrite made a maintained continuation possible.

- **Zolika1351** — author of ZolikaPatch, the original mod whose options,
  defaults, signatures and behaviour this project preserves.
- **GTAmodding / XLivelessAddon contributors** — the launcher/DRM bypass and the
  xliveless file layer the original loader descends from.
- **ThirteenAG and the FusionFix contributors** — the project layout, build and
  hook conventions this repository follows, the reference for compatibility
  work, and the intro/windowed logic used by the separate XLivelessAddon
  companion (GPL-3.0).
- **LINK/2012** — the `injector` memory-write library.
- **CitizenFX and ThirteenAG** — `Hooking.Patterns`.
- **ThirteenAG** — `IniReader`, the injector fork and the packaging conventions.
- **The readable reconstruction contributors** — the verified reimplementation
  of the original ASI from which the installer arms and hook bodies were ported.

The reconstruction and the readable rewrite were produced as clean-room studies
of the shipped binary. No original ZolikaPatch source was published, so no
original source is redistributed here.
